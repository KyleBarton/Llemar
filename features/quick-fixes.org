#+title: Quick fixes

* DONE Show diffs for write tool calls
Display =write= arguments as a path plus a syntax-highlighted, additions-only
Org =diff= source block, rather than duplicating the content in JSON. Label it
"Proposed file contents (entire file)" and render at call time, independently
of success or failure. This is a full-content preview, not a before/after diff:
overwrites do not show removed lines.

Keep the block expanded and complete regardless of the tool-result line cap.
Use only existing tool-call data, with no backend override or filesystem reads.
Cover live output before results, success/failure results, resumed history,
empty files, missing final newlines, whitespace, and Org escaping with
deterministic offline tests.

* TODO Move point to the buffer end when submitting a prompt
After a prompt is successfully submitted, move point in the submitting window
to the end of the conversation buffer so =llemar-follow-output= can follow the
response. This should work when =C-c C-c= is invoked from within a paragraph,
not just when point is already at the end.

Preserve the ability to scroll away afterward, and do not move point in other
windows viewing the conversation. Rejected or empty submissions should not
move point. Write deterministic offline tests before implementing.

* TODO Fully minimize tool-use headings by default
Ideally, tool-use Org headings should start fully folded, hiding their entire
subtree rather than leaving nested headings visible. Keep manual expansion
available, and cover both live output and resumed history.

* TODO Add a non-replacing conversation command
Provide an alternate command, tentatively =llemar-open-also=, that starts a new
conversation without replacing an existing Llemar buffer. Keep the usual
=llemar= replacement behavior unchanged. Unlike =llemar-other-window=, this
should not require opening another window; preserve the old conversation and
its process while displaying the new one in the current window.

Confirm naming and whether the existing command can share the implementation.
Cover invocation from both Llemar and non-Llemar buffers with offline tests.
