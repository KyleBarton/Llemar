#+title: Quick fixes

* TODO Resume sessions across working directories
=llemar-resume= should offer sessions from other folders, not just the current
working directory. Selecting one should start the resumed conversation and its
pi process in that session's recorded working directory, with the conversation
buffer's =default-directory= set accordingly. Do not require the user to change
directories before invoking resume, or change unrelated buffers' directories.

Preserve newest-first ordering, transcript previews, and the existing behavior
of replacing the current Llemar conversation. Show enough directory context in
the picker to distinguish sessions from different projects. Handle a missing or
inaccessible recorded directory explicitly rather than silently resuming in the
wrong folder; a failed startup must preserve the current conversation.
Cover cross-directory selection, buffer/process working directories, and failure
handling with deterministic offline tests before implementing.

* TODO Fold previous conversation headings after successful compaction
After confirmed successful compaction, collapse all previous conversation
headings, including earlier archives and retained messages, leaving the active
=User= prompt heading and its input area visible. In the current structure this
is =** User= under =* Current=; do not change heading levels to achieve folding.
Keep the necessary ancestor heading open and allow manual expansion of history.

Preserve unsent input and avoid stealing point from a user reading elsewhere.
For automatic compaction during an ongoing run, decide when to apply the final
folding so continued output remains visible and no premature user prompt is
created. Failed or cancelled compaction must not trigger this cleanup.
Extend the offline compaction scenarios to cover this presentation change.
See [[file:compaction.org][compaction history preservation]].

* DONE Resolve automatic paren and quotation pairing across messages
Identified =electric-pair-mode= with =electric-pair-preserve-balance= enabled
in the user's live Llemar buffers. Isolated Org-mode tests reproduced extra
quotes and closing parentheses caused by unmatched delimiters in history.
Setting =electric-pair-preserve-balance= to =nil= buffer-locally fixed these
cases while preserving ordinary pairing and skipping existing closing delimiters.

Resolved as a personal Emacs configuration matter, not a Llemar code change:
#+begin_src emacs-lisp
(add-hook 'llemar-mode-hook
          (lambda ()
            (setq-local electric-pair-preserve-balance nil)))
#+end_src
This disables balance preservation rather than restricting parsing to a heading.
The configuration snippet has not been installed or applied to live buffers
in this session; the user accepted closing the project item on this basis.

* DONE Show diffs for write tool calls

Org =diff= source block, rather than duplicating the content in JSON. Label it
"Proposed file contents (entire file)" and render at call time, independently
of success or failure. This is a full-content preview, not a before/after diff:

Keep the block expanded and complete regardless of the tool-result line cap.
Use only existing tool-call data, with no backend override or filesystem reads.
Cover live output before results, success/failure results, resumed history,
empty files, missing final newlines, whitespace, and Org escaping with
deterministic offline tests.

* DONE Move point to the buffer end when submitting a prompt
After a prompt is successfully submitted, move point in the submitting window
to the end of the conversation buffer so =llemar-follow-output= can follow the
response. This should work when =C-c C-c= is invoked from within a paragraph,
not just when point is already at the end.

Preserve the ability to scroll away afterward, and do not move point in other
windows viewing the conversation. Rejected or empty submissions should not
move point. Covered by deterministic offline tests, including submission with
following disabled and scrolling away before the reply finishes. Creating the
next User prompt no longer forces point away from history. Evil normal state's
post-command adjustment to the final character of a non-empty last line also
counts as the end for following; insert state and earlier positions do not.

* DONE Fully minimize tool-use headings by default
Tool-use Org headings start fully folded, hiding their entire subtree,
except for =edit= and =write= calls: those headings stay open so their diff
previews remain front and center. Manual expansion remains available for
other tools. Covered for live output and resumed history.
